# 对话校正行为回归

题面是用户红队场景与实际澄清的受控改写，不是独立效度数据。答题者只读分配版本的技能、题面及该题材料，不读预期、评分、其他版本结果或本说明以外的历史报告。

每题独立工作区。组织者提供 project/README.md、必要词表与 source.md，旧版和新版使用相同初始内容。答题者实际读取、查证；题面入口为 `$描述规范2` 的各题不修改词表，实际写入仅限获准写入的独立调用题面。把完整用户可见回答写入 response.md，把实际读取、写入、查证位置写入 actions.md。不向真实用户弹出测试问题，以问题草稿记录需澄清行为；因此这组测试不证明原生弹窗或宿主自动加载。

组织者另读预期，逐题核对完整答复、工具轨迹和前后文件差异。分别记录不必要追问、漏追问、误升级、来源错误及未执行动作。相同配置的一次回放不代表触发精确率的统计估计。

可运行 `python -X utf8 -B 测试-tests/检查接入.py --source <候选或安装的技能目录> --entry <描述规范2目录>` 检查文件和入口引用。它不调用模型，不检查中文等义；行为结果必须另行审阅。
