# 行为对照与触发验证（仅评测组织者读取）

本文件只用于维护并测试 `agent-rule-workbench` 本身。日常审阅或验证其他规则时使用该目标自己的材料，不进入本技能测试库。方法来源为仓库固定的 Anthropic `skill-creator`；上游文件用于维护本页，不是每次评测的运行依赖。

## 最小评测契约

1. 从用户要求和有效规则冻结可观察判据，准备原失败、正常路径、近似反例和最后才运行的留出材料；标明样本是真实、受控复现还是合成。
2. 旧版与候选使用相同初始状态、题面、权限、工具和模型设置，每个案例独立运行。答题者只读取分配的技能、题面和工作区，不读取判据、另一版输出或评分。
3. 检查最终产物、工具轨迹和副作用。改文件的任务必须产生满足要求的实际变化，未修版本至少有一项失败；未运行、环境失败和业务失败分开记录。
4. 运行后再按冻结判据评分；允许平局或证据不足。量表外实际缺陷仍阻断候选，旧评分不回改；用于选候选的材料不再算最终留出。
5. 逐例记录版本、输入、回复、必要轨迹和结果。只报告实际取得的重复次数、成本与效果；两版都通过或都失败不能被总分掩盖，未改善时停止追加指令。

比较获胜、空反馈或结构通过均不代表业务批准。组织者完成基础核查和独立审阅，用户只裁定真正的业务取舍。

## 分清三种验证

- **适用性**：检查请求是否应选用该技能，不证明宿主已经加载。
- **实际触发**：在目标宿主的新任务中只给普通请求和可发现入口，以可观察调用证明是否自动加载；无证据即记“原生自动触发未验证”。
- **使用效果**：显式提供技能后的产物对照，只证明加载后的行为，不冒充触发率。

## 本地确定性检查

在本技能目录运行：

```text
python 测试-tests/regression.py self-test
python 测试-tests/regression.py prepare
python 测试-tests/regression.py grade answers.json
```

`prepare` 只生成不含答案的题面，`grade` 逐例检查既有决策与来源结构；它们不调用模型、网络或收费 API，也不证明中文等价、真实任务质量或自动触发。模型回放和外部工具另按当前环境与授权执行，不安装或冒充运行上游 `claude -p` 脚本。

真实项目另用其正式规则、失败样本和正常场景验证实际动作与产物；本套自测不替代项目回归，也不固化已被用户改变的业务决定。
