## 阅读与状态维护

首页 README → [当前实现状态](当前实现状态.md)／[跨项目使用](跨项目使用.md) → 对应代码、规则和测试。本文集中维护仓库关系与同步要求。配音独立仓库建立后再提供其首页入口，历史资料从明确的历史入口进入。

配音业务范围为必要读法适配、原参考声音克隆、两层对照、按确认问题修复及音频交付，不包含字幕必经链。需求确定、设计完成、代码实现、实际验证和远端发布分别记录。中文谐音接入、无 FINAL 消费者适配和真实局部修复闭环仍须核查三文档之后的代码与产物；本次访问核实不重新判定其完成状态。

工作台组织专项交付，校验结构、来源和状态；不自动完成开放语义审阅、配音质量认证或业务实施。三文档检查或 G0 专项完成不等于配音工作流实现或业务验收通过。

## 每批同步闭环

1. 读取目标仓库可见性、分支及当前提交；核实本次已授权范围。
2. 在本地准备显式文件清单、差异和必要的本地来源映射；映射中的私有定位不进入仓库阅读版。
3. 检查实际待同步文本、敏感内容、UTF-8、相对链接、引用一致性及所涉测试。文档更新不冒充代码或业务验证。
4. 基于刚读取的远端版本同步选定文件；不得强推、覆盖未知变更或带入本地原始历史。
5. 从远端重新读取文件并逐字比对，复查仓库仍为 private，报告实际提交及剩余事项。接口成功、本地修改和远端完成分别记录。

不启用后台自动同步。后续每批变更沿用上述过程；源码、状态和阅读入口在同批更新，避免远端说明落后于实际交付。
