# v0.2.0 指导规则退役巡检

新增 `退役巡检`、`退役审阅` 与 `退役发现`专项，复用现有项目库、核心Skill及治理门禁。

支持整段指导及多跳指针取证、明示退役引用与结构信号、无信号语义复核队列、同版本去重、同位置正文或依据变化重开和到期复查。条目身份与正文版本分离；结构性编辑可能改变续接标注，但不得沿用旧处置压制复审。不会自动改写、归档、删除或批准业务规则。

增加受控的远端巡检入口：初始仅允许在 main 上手动派发，并要求显式确认本次 Issue 写入；main 变更和周期触发尚未启用。SQLite记忆保存在 Actions 产物，单个 Issue 只作通知索引。本地与云端库不自动同步。程序不调用模型，开放语义仍由已加载 Skill 的当前智能体核实。

保留既有能力；修复干净环境测试对临时目录的隐式依赖；修正README当前仓库可见性说明而保留历史记录。

本版本在发布工作流于 main 上被手动派发并显式确认 `publish_release` 后生成源码包；main 推送本身不创建 Release。精确运行与提交见该 Release 关联 Actions；测试覆盖不等于独立模型行为、配音质量或长期触发率证明。安装方式及日常入口见 README，方案与边界见 `说明-docs/指导规则退役发现-方案与验收.md`。
