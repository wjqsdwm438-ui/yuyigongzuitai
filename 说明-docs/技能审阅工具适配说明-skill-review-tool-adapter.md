# 工具适配说明

配合[《技能审阅与修改通用 SOP》](技能审阅与修改通用SOP-skill-review-sop.md)使用。遵循环境实际指令层级、用户授权及适用范围；工作台承担其被指定的任务选路职责，本说明不另设权限层级。

| 组件 | 对应步骤 | 职责与限制 |
|---|---|---|
| 审阅者（模型或人） | 3、7 | 判断语义、义务强度及适用范围；工具提供证据，自评不单独证明行为改善 |
| 工作台 | 1、3、6、7 | 组织来源、版本、变更分析及验证记录；程序结构校验不替代语义判断，专项提交不代表模型已运行 |
| writing-great-skills | 2、4 | 提供完成条件、信息层级、去重及分支组织方法；未提供专门的义务强度保真检查，不执行测试或授予权限 |
| skill-creator／quick_validate.py | 5、8 | 提供技能结构与配置方法；脚本检查元数据、命名和部分占位符，不检查引用存在性。其命名规则拒绝中文，是否与宿主规范一致需另核实 |
| 文件读取、搜索、差异比较及编辑工具 | 1、3、5、8 | 获取实际内容、核对引用、比较版本、备份、修改和读回 |
| 独立运行载体 | 6 | 经授权可使用不继承历史的子代理，并提供最小必要材料。只读指令不等于工具层隔离；文件副本也不隔离外部副作用 |
| `ms`（可选） | 1 | 整理自然语言需求；结果仍须对应原话和已采纳决定，不自动成为有效基线 |

## 工作台适配

- 能力和参数以实际程序、帮助及源码核实；文档与程序冲突时暂停相关操作并核实。
- `--项目` 指业务项目根；`--数据目录` 指定该项目的记录库位置。
- `--只读` 属于总入口参数，不是全局开关；案例诊断不支持该只读路径。
- 通用“授权实施”执行器尚未接通；获准的本地修改由文件工具完成。

## 按需组合

- 普通审阅：SOP＋文件工具，按问题选用写作或技能结构方法。
- 复杂维护：工作台“规则变更”，需要时加入历史回查或回归验证。
- 授权修改：文件工具实施，完成结构检查与必要行为验证；需留存记录时由工作台承接。
